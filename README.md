## Быстрый запуск Фронта

```bash
  cd ./frontend
  npm i
  npm run dev
```

## Быстрый запуск Бэка

```bash
  cd ./backend
  npm i
  npm start
```

## .env

```bash
  DB_USER=postgres
  DB_PASSWORD=your-password
  DB_NAME=postgres
  DB_HOST=localhost
  DB_PORT=5432

  JWT_SECRET=your-secret-key
  JWT_EXPIRES_IN=7d

  PORT=3000
```
